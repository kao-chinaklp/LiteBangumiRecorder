## LiteBangumiRecorder
这是一个比较垃圾的本地番剧收藏工具。

### 0 前言
这是一个基于 Python 的简单的本地番剧收藏工具，集成了简单的数据库存储（ SQLite ）。  
信息是从 [Bangumi](https://bgm.tv/) 获取的，使用了 Bangumi 的 API。
目前只实现了一些非常基础的功能，可能存在一些逻辑和性能问题，欢迎指出。

### 1 功能
- [x] 添加番剧到本地收藏
- [x] 删除本地收藏的番剧
- [x] 查看本地收藏的番剧列表
- [x] 查看番剧的详细信息
- [x] 通过某些 **tag** 搜索已存储的番剧
- [x] 显示所有的 **tag** 列表
- [ ] 设置搜索过滤器 / 标签过滤器
- [ ] 更好的模糊搜索

### 2 安装
1. 安装 Python 3.9 或更高版本
2. 安装依赖库
```bash
pip install -r requirements.txt
```
3. 运行程序

### 3 关于数据库
这个库有三个表：
- `animation`：存储番剧的基本信息
- `tag`：存储番剧的标签信息
- `animation_tag`：存储番剧和标签的关联信息

**animation_tag** 表是一个多对多的关系表，用于关联 animation 表和 tag 表，只存储动画和标签的 id。
